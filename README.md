# ✋ Virtual Hand Control

Control your PC with hand gestures using a webcam.

## Install
```
pip install -r requirements.txt
```

## Run
```
python virtual_hand_control.py
```

## Gestures
| Gesture | Action |
|---|---|
| ☝️ Index only | Move cursor |
| ✌️ Index+Middle close | Left Click |
| 🤏 Thumb+Index pinch | Right Click |
| 🖐️ All 5 fingers | Scroll |
| 🤘 Index+Pinky | Volume |
| 👌 Mid+Ring+Pinky | Brightness |
| 🤙 Thumb+Pinky | Toggle Keyboard |
| ✊ Fist | Freeze cursor |
